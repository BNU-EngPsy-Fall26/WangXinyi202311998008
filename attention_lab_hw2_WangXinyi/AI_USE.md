# AI 使用说明

本项目使用生成式 AI 辅助完成了以下工作：

- HTML / CSS / JavaScript 代码框架与调试建议；
- 数据导出、课程接口 POST、localStorage 备份逻辑；
- 结果可视化和参与者层级统计代码；
- README 与任务清单的结构化整理；
- 对实验方案提供了 AI 辅助草稿和文献核查，其中发现“Flanker 间距”已属于 Eriksen & Eriksen (1974) 原始操纵，因此未将其作为本项目新增条件。

以下内容应由本人独立核查和最终决定：

- 研究问题与改进条件是否采用；
- 收数前预测及其理论理由；
- 真实数据的解释；
- 是否支持预测；
- 与原论文的比较、局限和设计反思。


## 教育学主题化修改

本版本还由 AI 辅助完成了教育学选题框架建议、信号原则/图形知觉/认知负荷文献线索查找、网页教育学引言、结果后的理论思考、`EDUCATION_FRAMEWORK.md` 和相关 README 修订。以上均需由学生核查与独立决定是否采用；AI 未收集真实被试数据，也未替学生解释任何真实结果。
